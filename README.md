# PES-interleaved CFRP Interlaminar Fracture test Dataset

This repository contains the experimental data associated with the
investigation of Mode I and Mode II interlaminar fracture behaviour
of PES-interleaved CFRP laminates.

## Experimental Groups

- G1: CFRP without PES interleaf
- G2: Continuous PES interleaf
- G3: Uniform porous PES interleaf, 20.54% porosity
- G4: Hybrid porous PES interleaf, 30.21% porosity

## Tests

- Mode I: Double Cantilever Beam (DCB)
- Mode II: End-Loaded Split (ELS)

## Repository Structure

- DCB Data/: Mode I test data
- ELS Data/: Mode II test data
- All Date/: Processed and summary results

## Data Format

Experimental and processed data are provided in Microsoft Excel
(.xlsx) format.
